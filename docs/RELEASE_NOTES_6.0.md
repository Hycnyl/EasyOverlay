# EasyOverlay 6.0

- 推出独立的 EasyOverlay，新增快速使用：选图后直接显示，无需绑定应用。
- 重构应用规则，按应用和屏幕保存图片与不透明度，手动遮罩优先。
- 支持 PNG、JPEG、静态 WebP 和 GIF，新增私有图片库及图片复用。
- 新增双屏手动控制、悬浮球、实体键组合、快捷设置磁贴和通知停止入口。
- 新增 ImageOverlay 目录导入及 EasyOverlay ZIP 备份导入、导出。
- 采用 Material You 界面，支持动态配色及深浅色主题。
- 支持 Android 13 及以上，提供 universal APK。
