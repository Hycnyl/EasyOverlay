# EasyOverlay 6.1

在 6.0 已验收的快速使用基础上，加强应用自动切换及可选后台恢复，沿用原包名和发布签名，可直接覆盖升级。

- 新增无障碍窗口事件检测，提供 Shizuku 任务检测与 Usage Access 回退，设置和诊断显示实际检测来源。Dhizuku 按设备管理权限提供本应用通知授权管理，不冒充全局任务检测。
- 主屏无障碍可信遮罩可达 100%。快速使用和应用规则超过 80% 时提示，可选“不再提醒”；高值滑块始终红色。断开无障碍后限制到普通窗口安全值或关闭窗口。
- 新增简体中文 / English 切换，通知和诊断随语言切换。
- 新增“一键优化自动切换”：执行前展示仅针对 EasyOverlay 的通知、使用情况访问及系统电池白名单改动，保留原状态和恢复入口。
- 仅自动会话可尝试系统回收后的恢复；尊重应用/通知停止及 Android“停止应用”，重复恢复会退避。
- 删除 ImageOverlay 导入及实现，保留 EasyOverlay 自有备份；支持 6.0 数据升级。
- 图标主体缩至原尺寸 70%，提供同尺寸的动态主题单色图标。设置最下方新增关于页，含 Hycnyl 主页和仓库链接。

交付单一 `EasyOverlay-v6.1.apk`，包含 arm64-v8a、armeabi-v7a、x86、x86_64。签名沿用 6.0。发布资产附 SHA-256；私钥及密码不上传。

云端构建、自动测试、lint 和 AOSP Android 15 模拟器验证范围见 [VALIDATION_6_1.md](VALIDATION_6_1.md)。该记录不能代表 MIUI 长期后台或 Android 13/14/16 全部实体设备表现。无障碍、Shizuku、Dhizuku 和电池白名单均不能保证厂商永不清理后台。

本轮保留 compileSdk 36 / targetSdk 35 / minSdk 33；提高 targetSdk 36 仍等待实机前台服务复核。6.1 先以预发布交付测试，不修改已正式发布的 6.0。
